02 / Flagship · Final Year Project

AEGIS-LN

AI-Protected LoRa Mesh Communication System · Dual ESP32-S3
Phase III · 3,600+ LOC · C++ / Python

A decentralised mesh network that keeps nodes talking even when normal infrastructure is gone. There's no central server to take down. Every message is encrypted end to end, and an on-device AI firewall inspects traffic right there on the radio.

▤

Self-Healing Mesh Routing

Custom multi-path routing over 433 MHz LoRa, loosely based on AOMDV. No towers and no servers involved. Nodes find their neighbours on their own, and if a link dies the traffic just reroutes around it.

🔒

End-to-End Cryptography

Each session sets up its own key with ECDH (secp256r1). Traffic is encrypted with AES-128-CBC and authenticated using HMAC-SHA256 in an Encrypt-then-MAC scheme. All of it runs through mbedTLS on hardware with very little memory to spare.

🧠

Three-Stage AI Firewall

Traffic passes three checks before it's trusted. First a protocol-compliance test, then a metadata autoencoder that flags anomalies across a 17-feature, 16-packet window, and finally a DPI autoencoder that looks at the payload itself. The detection sits at the link layer, so it works on raw packets.

⚡

Edge ML, Quantised

Both detection models are TensorFlow Lite, quantised down to INT8 so they fit in 110 KB and 108 KB of flash. Inference takes under 50 ms on the ESP32-S3, which means the radio catches intrusions on its own without phoning home.

03 / Selected Work

The adversary-defender toolkit.

A mix of attack tooling and defensive systems I've built to learn how both sides of an engagement actually work.

/ 01
Offensive Infrastructure

Command & Control Framework

A modular C2 with a Flask REST API and a Python agent. Command and result traffic is encrypted end to end with a hybrid RSA-AES scheme, agents exchange a session key when they register, and they beacon back on a long poll with adjustable jitter. It can also pull files off a target. I built it to understand how real attacker infrastructure is put together.

FlaskRSA + AESPythonC2 Tradecraft
/ 02
Active Defence · ML

Adaptive Honeypot System

A honeypot that pretends to be SSH and HTTP services so real attackers will poke at it. A behavioural profiler and an ML decision engine work out what the attacker is trying to do and change the fake responses on the fly. The point is to gather threat intel automatically while they think they're making progress.

SSH / HTTP EmulationBehavioural MLThreat Intel
/ 03
Wireless Attack · Embedded

ESP32 PMKID Capture Tool

A small WiFi auditing tool that runs on an ESP32 and grabs PMKID material from WPA/WPA2 access points. You take that material offline and try to recover the key. It's a cheap, pocket-sized rig for wireless pentests and for showing people how weak a lot of Wi-Fi setups really are.
